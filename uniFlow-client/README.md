# uniFlow: Client Web Form

The public page opened by scanning a device's QR code: service request form with photo upload, service rating page, and a printable page of all asset QR codes (`/qrs`).

```bash
npm install
npm run dev   # http://localhost:5555
```

Set `VITE_API_BASE_URL` in `.env` to the backend URL. See the [root README](../README.md) for the full system.
