# uniFlow: Operator Dashboard

Login-protected dashboard for reviewing, scheduling, assigning, and closing service requests, with live Socket.io updates, asset and technician views, and analytics.

```bash
npm install
npm run dev -- --port 4000   # http://localhost:4000
```

Set `VITE_API_BASE_URL` in `.env` to the backend URL. See the [root README](../README.md) for the full system.
